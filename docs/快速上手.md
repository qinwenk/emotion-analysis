# 第一次使用：安装 → 同步聊天 → 说出需求

这套工具会从你的电脑微信取得指定会话，导入 ChatLab，再由 Codex 分析双方意愿、适配程度和关系卡点。你不用自己找密钥、配置 Python，或学习导入命令。

**准备好一台 Windows 64 位电脑、能够正常使用的 Codex，以及你本人登录的手机微信和电脑微信。** 当前自动取钥只适配电脑微信 **4.1.15.56**；其他版本会停止并说明原因。不要为了使用工具自行卸载或降级微信。

## 1. 安装一次

1. 打开 [GitHub 仓库](https://github.com/qinwenk/emotion-analysis)，点击 **Code → Download ZIP**。
2. 解压 ZIP，打开能看到 `Install.cmd` 的文件夹。不要在压缩包里直接运行。
3. 双击 **Install.cmd**，保持联网，等待安装和环境检查完成。

安装器会配置专用运行环境、ChatLab CLI 0.37.7，以及三个 skill：主流程、证据检索、关系分析。它不会读取微信聊天。Codex 本身需要你事先安装并登录；无需为本工具另外申请开发者 API Key。

不熟悉文件操作，也可以把解压文件夹的完整地址发给 Codex：

```text
请安装这个文件夹里的情感分析工作流，连同运行环境和配套 skill，完成环境检查。
文件夹地址是：这里换成你的解压文件夹完整地址
```

安装后，在下一轮对话中就可以调用。若提示找不到 skill，重新打开一个 Codex 对话再试。不了解微信版本时，可以先说：“使用 $chat-relationship-workflow，先检查我的电脑微信是否兼容，暂时不获取聊天。”

## 2. 让所需历史出现在电脑微信里

**目标是：打开电脑微信中这个人的对话，能查到你想分析的历史。** 只看到“备份完成”还不够；腾讯的“备份与恢复”用于把备份恢复到手机，与本流程使用的电脑聊天记录是不同来源。[腾讯客服说明](https://kf.qq.com/faq/161224mmmUju161224A3UVrE.html)

1. 手机和电脑连接同一网络，并在两边登录同一个微信账号。
2. 在**手机微信设置**里，按实际界面选择下面的一种入口。

| 你看到的菜单 | 进入哪里 |
| --- | --- |
| “聊天记录管理” | 聊天记录管理 → 导入与导出 → 导出到电脑。有些手机把入口放在“通用”里。 |
| “聊天记录迁移与备份” | 通用 → 聊天记录迁移与备份 → 迁移 → 迁移至电脑。 |

这两种入口分别见华为官方的[聊天记录导出说明](https://consumer.huawei.com/cn/support/content/zh-cn01118496/)和[迁移至电脑说明](https://consumer.huawei.com/cn/support/content/zh-cn16058724/)。菜单随手机系统及微信版本变化，**看到哪一种就用哪一种**；如果都没有，把当前菜单名称告诉 Codex，由助手继续协助。

3. 选择要分析的联系人。出现“仅导出指定聊天记录”时，用它选择目标会话；若没有日期筛选，可先同步该会话，之后再由工具筛日期。
4. 按微信提示在电脑确认接收。传输期间保持设备联网、微信开启，等待两端完成。
5. 在电脑打开目标对话，查找所需时间范围内较早的一条和最近的一条消息。能看到后保持电脑微信登录，再开始分析。

登录时的“同步最近消息”不代表同步了全部历史。上述查看只是初步检查，工具会在解密后报告**实际可取得的起止时间和条数**，不能据此保证手机全部历史都齐全。

## 3. 把这段话发给 Codex

替换联系人和日期即可，不知道的背景可以不填：

```text
使用 $chat-relationship-workflow。
我已经把需要的聊天同步到电脑微信，并保持登录。
请获取我与“小林”最近三个月的聊天，导入 ChatLab 后分析：
1. 对方有没有发展恋爱关系的意愿；
2. 我们的适配程度和关系卡点；
3. 关系变化的关键节点，以及值得深入分析的情绪场景；
4. 针对当前困境，给我一个可执行的下一步。
先告诉我实际取得的时间范围；有缺口请说明，不要猜测。
结果保存在我的“文档”中的“关系分析结果”文件夹，每次新建一个任务目录。
```

时间也可以改成“2026 年 1 月 1 日到 3 月 31 日”或“电脑上能取得的全部历史”。有同名联系人或多个微信账号时，助手会请你确认一次。

**想法还没确定，就直接说出来。** 例如：“我也还在判断是否想和对方谈恋爱，请先帮我了解自己的需要，不要把所有建议都导向表白。”如果助手误解了玩笑，也可以说：“那次主要是在互相逗，我没有很难受，请据此更新判断和建议。”

回答会先给当前判断，再说明关键事件与仍不确定的部分；需要建议时，会结合已经试过的做法，给出下一步、观察什么反馈以及何时调整。你只要一句回复时，直接说明即可。口述补充会标明来源，账号核对不代表能验证真人身份或保证陈述真实；只有片段也能分析，但不会假称读过全部历史。

如果只想拿旧报告作试验或改进 skill，可以明确说“保留旧报告，只优化输出模式”；此时不会回写旧报告。详细规则见[输出模式定义](../skills/chat-relationship-workflow/references/output-mode.md)。

## 后续怎么用

- **继续讨论已有结果**：“继续上次的分析。我最在意的是……请结合原来的证据再看。”不必重新同步和导入。
- **增加新聊天**：先把新增历史同步到电脑，再说：“获取上次之后的新记录，更新原会话和分析；这次另建任务目录。”工具会核对重复记录。
- **记录不够**：把缺失日期告诉助手，补齐同步后重新获取；不要把 `Backup` 文件夹当作电脑会话目录。
- **安装失败或提示版本不支持**：把报错原文发给 Codex。不要自行修改数据库或卸载微信来尝试解决。

你会得到实际记录范围、关系分析报告和可追溯的证据。语音和图片可能只有类型占位，不能当作已经听过或看过。解密解析在本机完成，分析仍使用当前 Codex 模型服务；私人聊天、密钥和报告不要上传公开仓库。

需要查看具体参数时，再读[电脑端自动流程](../skills/chat-relationship-workflow/references/desktop-automation.md)。
